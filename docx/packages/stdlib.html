标准库 stdlib

Dial 的标准库，随编译器发布、编译你的程序时自动链入，无需 install、 也无需在源码里 import（编译器前端直接认得 Db / string / int[] 等内置类型）。 它把「字符串 / 动态数组 / 哈希表 / IO / 内存管理 / 并发」这些一切容器与运行时 能力用 C 实现，Dial 侧只负责把调用翻译出去——这正是「C 承担一切容器」的设计。

  • 类型系统基石：string（UTF-8 不可变字节序列，ARC 拥有）、int[] / float[] / byte[] / char[]（动态数组，put 触发扩容或写时复制后由编译器把 新指针写回接收变量）、map<K,V>（ARC + COW 哈希表）。
  • 不透明指针契约：string 与数组在 IR 中只是 ptr，用户代码永远无法触碰其 内部布局，一切经由 C 导出函数——库作者随意重构、调用方零改动。
  • 并发底座：thread / channel<T>（原子 ARC 共享，move_to 转移所有权取代锁）、 spawn / select / close / done / try_recv / recv_timeout。
  • Fail-Fast 内存宪法：绝不引入追踪式 GC；确定性内存靠 ARC + 编译期逃逸分析 / 移动语义，裸指针坚持「谁申请谁释放」。

标准库是 MIT / Apache-2.0 许可（与编译器本体的 GPL 三选一隔离），因此被 静态链进你程序里的运行时不受 GPL 条款约束——工具可以是 GPL，被链进你程序的 运行时绝不能是。

详见 语言规范（README 全文即规范）。
