[v1.02] — 2026-11-05 · 理由与证据链

本文件是 CHANGELOG.md 中 ## [v1.02] — 2026-11-05 版本段拆出的「理由 / 证据链」存档：为什么改、实测数据、边界在哪。 变更条目（新增 / 更改 / 破坏性变更 / 修复）本身仍留在 CHANGELOG.md。

底层控制三件套：goto + 标签、with 资源作用域块、裸指针 rawptr<T>。

三样互为因果：goto 是底层清理的利器，但无限制乱跳会把程序打崩，因此配三条死锁； 死锁之一是「不得跳出 with 块」，所以要先有 with；而 with 要能自动释放裸指针， 于是裸指针必须先落地。

本版继续守住项目铁律：不引入 GC；ARC 所有权语义不退化；零隐式转换 （裸指针与 ARC 容器之间、裸指针与裸指针之间都没有隐式转换）。

测试

  • 3 个新增正向示例 + 同名 .expected 黄金文件：goto_demo、with_demo、rawptr_demo；
  • 12 个新增负向用例：跨初始化（同块 + 跨块）/ 跳出 with / 跨 try / 跳进嵌套块 / 未定义标签 / 对 let 取址 / 解引用非指针 / rawptr<void> 算术 / free 非指针 / with 非资源 / 裸指针隐式转换；
  • bash tests/run_tests.sh A–O 全套通过；H 组另加一条回归：drop(不透明句柄) 必须报错并给出「不受 ARC 管理、请手动释放」的指引。
