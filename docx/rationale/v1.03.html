[v1.03] — 2026-11-05 · 理由与证据链

本文件是 CHANGELOG.md 中 ## [v1.03] — 2026-11-05 版本段拆出的「理由 / 证据链」存档：为什么改、实测数据、边界在哪。 变更条目（新增 / 更改 / 破坏性变更 / 修复）本身仍留在 CHANGELOG.md。

回调与可变参数：一等函数指针 fn(A, B): R、同类型变参 ...xs: T、 extern fn 的 C 风格异构变参（FFI 特例），以及接受回调的 stdlib 高阶数组方法 map / filter / sort_by。

三件事互为因果：回调要用函数地址，于是先有函数指针；变参要接住「一批同类型实参」， 于是脱糖成数组；而高阶方法正好是「回调 + 一批元素」的组合，用来验证前两者在真实 调用链里不会引入隐藏开销。

本版继续守住项目铁律：不引入 GC；不引入闭包（绝不隐式捕获环境）； 零隐式转换（函数签名严格匹配、变参元素类型严格一致）； 零隐藏开销（变参脱糖成普通 T[]，没有类型标签 / 装箱 / 运行期分派）。
