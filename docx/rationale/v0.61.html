[v0.61] — 2026-10-29 · 理由与证据链

本文件是 CHANGELOG.md 中 ## [v0.61] — 2026-10-29 版本段拆出的「理由 / 证据链」存档：为什么改、实测数据、边界在哪。 变更条目（新增 / 更改 / 破坏性变更 / 修复）本身仍留在 CHANGELOG.md。

本版落地文件 IO（file 句柄）（见 README §24），并正式确立版本号规则（最多两位小数、禁止跳版、严格按时间递增，见 README §23）。

设计约束（用户拍板）

  • 绝不引入可变全局状态：文件句柄显式传递（v1.04 §37.1 统一措辞，原写作「绝不引入全局变量」）。
  • 底层走 C 标准库：直接封装 FILE*，不在 Rust 前端重写文件系统逻辑。
  • 错误处理（无异常）：打开失败返回空指针、读失败返回空串、写失败返回 -1；不引入 Result 封装。
  • 不搞花哨语法：只做 open / read / write / close 基础 API，无链式文件读取流。
