HTTP 客户端包 http

自研 HTTP/1.1 + TLS 1.3 + keep-alive + HTTP/2 客户端，零第三方 HTTP 栈 （自写报文解析 / Header 拼装 / Socket 读写），TLS 走 vendor 的 mbedTLS。 覆盖面积从普通 GET/POST 到真实并发多路复用的 h2。

  • 高层 API：http_get / http_post 一行到位（响应头 / 404 / gzip 解压 / chunked 全处理）；http_request 暴露超时 / 自定义头 / 代理画像。
  • 低层流式：http_stream_* 边读边处理大响应，不把整响应塞进内存。
  • HTTP/2：h2c 明文 + h2 ALPN 双路径；自研 HPACK（含 Huffman）、单连接 真·并发多路复用（reader 线程 + spawn worker），超长额外头不截断。
  • TLS 1.3：证书校验 fail-closed（空 CA 目录也拒绝）、keep-alive 连接池复用。
  • Fail-Fast：chunked 畸形长度行当场失败、合法 chunk-ext 不误伤；错误路径 明确返回错误码，绝不静默损坏。
import "http";

fn main(): int {
    let r: HttpResp = http_get("https://example.com/");
    if (not is_null(r)) {
        print(r.status_code);
        print(string_from_cstr(r.body));
    }
    return 0;
}
