GUI 地基包 gui

不用 Qt / GTK / SDL，纯 C 手搓的 GUI 包，前七层 + 第 9/10 层滚动视图与右键上下文菜单是 C 契约、 共 184 个 extern fn：地基（窗 + 事件 + 绘图 + 字体）/ 控件框架层（Widget 树 + 布局 + 命中 + 主动分发）/ 成品控件外观层（Label / Button / CheckBox + 主题表驱动四态）/ 输入层（TextBox + 焦点链 + 统一功能键码 + XTest 实窗注入）/ 主题层与控件扩展 （14 个可覆写颜色角色 + Radio / Slider / ProgressBar）/ 信号槽（6 类可订阅纯值 信号 + 每树环形队列）/ 菜单·对话框覆盖层（顶栏菜单 + 弹出菜单 + 模态对话框， 复用纯值信号队列）/ 滚动视图层（视口裁剪 + 滚动条几何 / 命中 / 绘制 + 偏移推进 wheel / drag / scroll_to，越界自动夹紧，零 DISPLAY 依赖，见 §38.15）/ 右键上下文菜单层（复用第 7 层 GuiMenu + 弹出锚点 + 命中 / 悬停 / 选中 / 绘制， 借用语义不转移菜单所有权，零 DISPLAY 依赖，见 §38.16）。第 8 层是 Dial 侧 OO 封装层（gui_oo.dial，183 个 impl 方法把上述 C 风格函数包成 win.draw() 这样的惯用写法，纯 Dial 源码、不进 .dialpkg、零 extern fn 增量、ABI 不变，见 §38.14）。

import "gui";

fn main(): int {
    let app: GuiApp = dial_gui_app_new();
    let win: GuiWindow = dial_gui_window_new(app, "Hello GUI", 400, 300);
    let root: GuiWidget = dial_gui_widget_tree(400, 300);
    let btn: GuiWidget = dial_gui_widget_add(root);
    dial_gui_widget_set_rect(btn, 10, 10, 80, 24);
    dial_gui_widget_set_kind(btn, 2);            // BUTTON
    dial_gui_widget_set_text(btn, "Click me");
    dial_gui_widget_subscribe(btn, 1);           // CLICKED
    dial_gui_window_set_root(win, root);
    dial_gui_window_draw(win);
    dial_gui_window_flush(win);
    dial_gui_window_close(win);
    dial_gui_app_free(app);
    return 0;
}

第 8 层：同一套能力也能写成方法。把 gui_oo.dial 放进项目目录， import "./gui_oo.dial"; 一行即生效（模块内已传递 import "gui";，前端会汇总去重）：

import "./gui_oo.dial";

fn main(): int {
    let app: GuiApp = dial_gui_app_new();
    let win: GuiWindow = app.window_new("Hello GUI", 400, 300);
    let root: GuiWidget = app.widget_tree(400, 300);
    let btn: GuiWidget = root.add();
    btn.set_rect(10, 10, 80, 24);
    btn.set_kind(2);
    btn.set_text("Click me");
    btn.subscribe(1);
    win.set_root(root);
    win.draw();
    win.flush();
    win.close();
    app.free();
    return 0;
}

impl 在 parser 阶段就降级为普通函数，obj.m() 在语义与代码生成两处就地改写成 Expr::Call 复用整条调用链——同一绘制序列以两种风格执行，painter_crc32() 逐字节相等，产物与 ABI 不漂移。B1 现役边界：不支持关联函数，故 app 自身仍用 dial_gui_app_new()；工厂以 app.window_new(...) 等形式提供（self 仅作命名空间）。

  • 三平台真实现：x86_64-linux-gnu / aarch64-unknown-linux-musl / x86_64-pc-windows-gnu 均由 zig cc 交叉编译出真实 .a，零链接期 GUI 依赖 （X11 / Win32 一律 dlopen / LoadLibraryA），最终链接不需要 -lX11 / -lgdi32。
  • 绝不 C → Dial 反向回调：事件 / 信号一律「C 写纯值块，Dial 主动 pending → data → pop 消费」——符合内存宪法。
  • ABI 不变：只追加 extern fn，旧签名一字不动；覆盖层不进控件树，控件几何 / 绘制 CRC 逐字节不漂移。
