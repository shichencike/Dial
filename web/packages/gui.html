GUI 地基包 gui

不用 Qt / GTK / SDL，纯 C 手搓的 GUI 包，前七层 + 第 9/10/11/12/13/14/15/16/17 层滚动视图·右键上下文菜单·悬浮提示·状态栏·通知气泡·窗口级覆盖层自动集成·快捷键 / 命令系统·网格布局 GRID + 组合框 ComboBox + 列表框 ListBox + 右键·滚轮交互·撤销/重做 + Slider 拖动 + 每控件主题覆写 + Grid 自动换行是 C 契约、 共 318 个 extern fn：地基（窗 + 事件 + 绘图 + 字体）/ 控件框架层（Widget 树 + 布局 + 命中 + 主动分发）/ 成品控件外观层（Label / Button / CheckBox + 主题表驱动四态）/ 输入层（TextBox + 焦点链 + 统一功能键码 + XTest 实窗注入）/ 主题层与控件扩展 （14 个可覆写颜色角色 + Radio / Slider / ProgressBar）/ 信号槽（6 类可订阅纯值 信号 + 每树环形队列）/ 菜单·对话框覆盖层（顶栏菜单 + 弹出菜单 + 模态对话框， 复用纯值信号队列）/ 滚动视图层（视口裁剪 + 滚动条几何 / 命中 / 绘制 + 偏移推进 wheel / drag / scroll_to，越界自动夹紧，零 DISPLAY 依赖，见 §38.15）/ 右键上下文菜单层（复用第 7 层 GuiMenu + 弹出锚点 + 命中 / 悬停 / 选中 / 绘制， 借用语义不转移菜单所有权，零 DISPLAY 依赖，见 §38.16）/ 悬浮提示层（文本 + 位置 + 尺寸 + 悬停计时，延迟由调用方推进、零时钟依赖， 零 DISPLAY 依赖，见 §38.17）/ 状态栏层（左 / 右文本 + 进度条槽位，进度值越界夹紧，零 DISPLAY 依赖，见 §38.18）/ 通知气泡层（FIFO 消息队列 + 生命周期纯值推进、到期自动消隐，零 DISPLAY 依赖，见 §38.19）/ 窗口级覆盖层自动集成（5 类覆盖层挂到窗口槽位，win.draw() 按固定 z-order 自动叠加： 滚动条 → 上下文菜单 → 悬浮提示 → 状态栏 → 通知气泡；窗口借用对象、只持指针不释放， 空槽位零像素影响、既有 CRC 逐字节不破，见 §38.20）/ 快捷键 / 命令系统（dial_gui_hotkey_*：按键组合 (key, mods) → 命令 id 的纯内存表 + 命令启用态；bind 冲突 Fail-Fast / rebind 覆盖 / unbind 压实 / dispatch 只发启用 且命中的命令（语义归应用、C 侧零反向回调）；容量 64、命令 id [0, 256)；空表零像素影响、 重绘幂等，纯 C 零平台符号、零时钟、零 DISPLAY 依赖，见 §38.21）。 网格布局 GRID（set_grid / set_grid_cell：set_layout 接受 mode 3，容器声明 cols×rows、子节点声明占格，弹性均分几何、越界 Fail-Fast 拒绝而非静默截断，纯几何 headless 可测，见 §38.22.1）/ 组合框 ComboBox（dial_gui_combo_*：kind=10、只读框 + 点击展开下拉、单选取值、项容量 64 固定、label 经 DialString 由 C 侧造副本、 item_label 返回借用指针、点击框体切展开、下拉项命中选中并发 SELECTED，见 §38.22.2）/ 列表框 ListBox（dial_gui_list_*：kind=11、与 Combo 共用 items、单选 select + 多选 select_toggle 的 64 位位图、is_selected / selected_count / selected_first、 点击行选中并发 SELECTED，见 §38.22.3）/ 右键·滚轮交互（button==3 置 right_pressed 纯值态、RELEASE 清、与 left pressed 平行不串扰；滚轮 button==4/5 命中 SLIDER 按 step=span/100 增减并 clamp、落非 SLIDER 零影响，set_kind 上界由 7 扩到 11（8 / 9 信号 kind 标记仍显式拒绝，四处断言锁死），见 §38.22.4）——以上第 16 层共 23 个 extern fn、旧签名一字不动，纯 C 零平台符号、 零时钟、零 DISPLAY 依赖，见 §38.22）。 第 17 层（16 个 extern fn，见 §38.23）：TextBox 撤销 / 重做（快照式历史， 键盘编辑改文本前把「文本 + 光标 + 选区」入 undo 栈、新编辑清 redo、容量 32 固定、 显式 set_text 建新基线不进历史，见 §38.23.1）/ Slider 拖动（PRESS 置 drag_active 不改 value、MOVE 按绝对 x 设值并 clamp、拖出控件仍生效、RELEASE 清态， 见 §38.23.2）/ 每控件主题覆写（ov_mask 位图标记覆写角色、未覆写逐像素回落 进程级全局表、color=0 合法、clear 后 CRC 回历史基准，见 §38.23.3）/ Grid 自动换行（容器开关打开后按加入顺序自动依次占格、显式 col/row 被忽略、 cspan 仍生效、溢出夹末行，见 §38.23.4）。四组能力未启用时逐像素等价于旧路径， 故第 1~16 层既有 CRC 钉值一字未改、七个既有 demo 在新内核下重跑仍 0 bad。 第 8 层是 Dial 侧 OO 封装层（gui_oo.dial，317 个 impl 方法把上述 C 风格函数包成 win.draw() 这样的惯用写法，纯 Dial 源码、随包 src/ 分发（装包即用）、零 extern fn 增量、ABI 不变，见 §38.14）。

import "gui";

fn main(): int {
    let app: GuiApp = dial_gui_app_new();
    let win: GuiWindow = dial_gui_window_new(app, "Hello GUI", 400, 300);
    let root: GuiWidget = dial_gui_widget_tree(400, 300);
    let btn: GuiWidget = dial_gui_widget_add(root);
    dial_gui_widget_set_rect(btn, 10, 10, 80, 24);
    dial_gui_widget_set_kind(btn, 2);            // BUTTON
    dial_gui_widget_set_text(btn, "Click me");
    dial_gui_widget_subscribe(btn, 1);           // CLICKED
    dial_gui_window_set_root(win, root);
    dial_gui_window_draw(win);
    dial_gui_window_flush(win);
    dial_gui_window_close(win);
    dial_gui_app_free(app);
    return 0;
}

第 8 层：同一套能力也能写成方法。装好 gui.dialpkg 后，包内 src/gui_oo.dial 会随包分发；写一行裸名 import 即用，无需复制任何文件到项目目录 （模块内已传递 import "gui";，前端会汇总去重）：

import "gui_oo";

fn main(): int {
    let app: GuiApp = dial_gui_app_new();
    let win: GuiWindow = app.window_new("Hello GUI", 400, 300);
    let root: GuiWidget = app.widget_tree(400, 300);
    let btn: GuiWidget = root.add();
    btn.set_rect(10, 10, 80, 24);
    btn.set_kind(2);
    btn.set_text("Click me");
    btn.subscribe(1);
    win.set_root(root);
    win.draw();
    win.flush();
    win.close();
    app.free();
    return 0;
}

impl 在 parser 阶段就降级为普通函数，obj.m() 在语义与代码生成两处就地改写成 Expr::Call 复用整条调用链——同一绘制序列以两种风格执行，painter_crc32() 逐字节相等，产物与 ABI 不漂移。B1 现役边界：不支持关联函数，故 app 自身仍用 dial_gui_app_new()；工厂以 app.window_new(...) 等形式提供（self 仅作命名空间）。

  • 三平台真实现：x86_64-linux-gnu / aarch64-unknown-linux-musl / x86_64-pc-windows-gnu 均由 zig cc 交叉编译出真实 .a，零链接期 GUI 依赖 （X11 / Win32 一律 dlopen / LoadLibraryA），最终链接不需要 -lX11 / -lgdi32。
  • 绝不 C → Dial 反向回调：事件 / 信号一律「C 写纯值块，Dial 主动 pending → data → pop 消费」——符合内存宪法。
  • ABI 不变：只追加 extern fn，旧签名一字不动；覆盖层不进控件树，控件几何 / 绘制 CRC 逐字节不漂移。
