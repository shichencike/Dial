[v1.0 里程碑] — 分版记录（v1.00 ~ v1.03）

里程碑与标签：v1.00 是从 v0.99.1 跳版而来的语言特性补齐里程碑，当时 「回调 / 可变参数」等收尾特性尚未完成。到 [v1.03] 这些收尾特性已全部落地并 回归通过（A–O 全绿、330 ✅ / 0 ❌、零编译警告），里程碑标签 v1.0 已打并推送； 在后续 CI 修复完成后，该标签被删除并重新指向里程碑收尾的最新提交（见 上方「CI 修复与 v1.0 标签重打」章节）。下面四个版本条目统一归到本里程碑之下， 作为达成过程中的分版记录，而不是四个各自独立的「正式 v1.0」。

分版 主题
[v1.00] 语言特性补齐（五组）+ 泛型容器
[v1.01] 按「真实程序」盘点后的缺口补齐
[v1.02] goto / with / 裸指针，并补齐不透明句柄契约
[v1.03] 回调（函数指针）与可变参数

两类标签互不替代：v1.0 标记里程碑达成；按版本号的发布标签（v*）用于 触发 CI 产出带全部资产的 Release。一键安装脚本不依赖精确版本标签——它通过 GitHub API 解析最新 Release 的真实资产名并走 releases/latest/download/， 因此发新版时无需改脚本、也无需补打配套标签，详见下方「安装与发布流程调整」。
