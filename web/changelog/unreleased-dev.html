[未发布] — 开发中增量（未升版本号 / 未打标签 / 未发 Release）

主题：手搓 GUI 地基包 gui.dialpkg + 控件框架层。 详见 README §38。

版本与交付口径（防漂移，务必先读）：本段记录的是 [v1.10]（Git 标签 v1.1） 发布之后、仍在工作树里的开发中增量——本轮只要求「制作 gui.dialpkg 原型 + 完整工程骨架」，没有要求升版本号、打标签或发 Release。因此 Cargo.toml 仍为 1.10.0、dialc --version 仍输出 dialc 1.10.0、 README 首行与官网 KPI 仍是 v1.10，不新增 [v1.11]：那会让文档版本号与 Cargo 版本对不上，正是要避免的漂移。待用户决定发版时，再把本段归并进对应 版本标题，并在 §23 规则下同步所有载体。

[v1.10] 段的「A–Z 二十六组 / 499 ✅」是 v1.1 标签发布时的验收快照， 保持原文不改；地基层增量把回归扩到 A–Z + AA 二十七组 / 507 ✅，本轮 控件框架层再给 AA 组增 3 条断言到 510 ✅。三者是不同时点的真实记录， 不是互相矛盾。§33.17 的 499 ✅ 同理，仍为发布快照。

Added

  • gui.dialpkg：手搓 GUI 地基包 + 控件框架层（README §38）：不用 Qt / GTK / SDL， 纯 X11 自绘。地基层是窗 + 事件 + 绘图；本轮在其上补齐控件框架层 （Widget 树 / 绝对·VBox·HBox 布局 / 命中测试 / 主动事件分发）。 成品控件外观 / 信号槽 / C→Dial 回调仍不进 .diali 契约——把未实现函数写进 契约会让用户 import 后链接失败，那是制造漂移而非预留接口。
  • 自研迷你 2D 光栅化器：ARGB32 像素缓冲、source-over alpha 混合、 1/2/4/8 档覆盖面积采样抗锯齿、矩形 / 线 / 圆 / 圆环 / 椭圆 / 梯形 / 位图 / 裁剪 / 像素读写；dial_gui_painter_crc32() 提供像素级回归断言。
  • 字体层：内置 8×8 ASCII 点阵（零运行依赖兜底）+ vendor stb_truetype.h v1.26 （MIT）做 TrueType 字形栅格化；只加载本机可信字体文件（≤ 64 MB）， 绝不解析不可信 / 网络字体（上游明确 NO SECURITY GUARANTEE）。
  • Linux / Termux 后端（真实现）：libX11 / libXext / libXrender 一律 dlopen + dlsym 动态装载；XShm 共享内存离屏画布 + XRender Picture/Filter 合成，自定义 XSetErrorHandler 把异步 X11 错误转成 Dial 返回码 + 错误槽， 避免 Xlib 默认处理器 exit(1) 带走宿主进程。
  • Windows 后端（真实现）：LoadLibraryA("user32.dll") / gdi32.dll 动态解析， CreateDIBSection 32bpp top-down BGRA + CreateCompatibleDC / StretchBlt， SetStretchBltMode(HALFTONE) 对应 XRender 平滑 filter；Win32 消息循环映射统一事件码。 沙箱只能交叉编译、不能实机运行，平台边界如实标注。
  • 三平台 .a 零链接期依赖：x86_64-linux-gnu / aarch64-unknown-linux-musl / x86_64-pc-windows-gnu 均由 zig cc 一次交叉编译；nm -u 断言 .a 不含 XOpenDisplay / XShmCreateImage / XRenderComposite / CreateDIBSection / CreateWindowExA 等平台 GUI 未定义符号，dialc 最终链接不需要新增 -lX11 / -lgdi32。
  • 控件框架层（28 个新 extern fn + type GuiWidget）：并入同一个 gui 包 （.diali 不透明句柄按包隔离、跨包引用不可行），旧 55 个签名一字不动、 abi = 6 / version = 1.10.0 不变，仅重新 pack + install（同 ABI 覆盖）。 新增 dial_gui_widget.c 是纯 C、不碰任何平台 API，三份 .a 仍无 GUI 链接期依赖。
  • 独立纯内存树根：dial_gui_widget_tree 不连显示服务器，无 DISPLAY 环境也能 完整验收布局 / 命中；挂窗后由窗口拥有，随 window_close 释放。
  • 布局：绝对 / VBox / HBox 三种，纯整数、固定尺寸优先扣减、gap/padding， 幂等（每次从 req_* 重算，不把上轮弹性尺寸误当固定）。
  • 命中测试：后加子优先、取最深可见 Box；放在后端 pump 的 Dial 调用线程， 绝不进 wndproc 系统回调。
  • 主动事件分发 + 零越界（内存宪法）：绝不做 C → Dial 反向回调。C 侧只写 一块 __attribute__((packed)) 纯值块 GuiWidgetEvent（104 字节），Dial 侧 poll/wait 后经 rawptr<byte> + ptr_cast 读纯值；win_title / widget_id 是 C 侧借用指针，必须 string_from_cstr 复制成自己的 ARC 对象。 C 管 C 的，ARC 管 ARC 的，零隐式开销。
  • 布局双向锁死：C 侧 _Static_assert(sizeof==104, offsetof(...)) 与 Dial 侧 sizeof<T>() / alignof<T>() / offsetof<T>(field) 编译期内建逐项比对， 任何字段增删两边同时报错。
