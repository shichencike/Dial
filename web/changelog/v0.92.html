[v0.92] — 2026-10-31

本版落地 char 单字符类型（见 README §5.4）， 并集中修复了一批宪法级文档自相矛盾与一个真实的运行时缺陷。

Added（新增）

  • char 类型：一个 Unicode 码点。值类型、无 ARC、无堆分配、无空指针， IR 层与 int 同为 i64，但类型独立。
  • 字符字面量 'a' / '中' / '\n'，支持 \n \t \r \0 \\ \' \" 转义； 空 '' 与多字符 'ab' 在词法阶段即被拒绝（它们根本不是一个字符）。
  • 比较运算：== != < > <= >= 按码点序比较（'a' < 'b' 为真）。
  • 零成本显式转换 char_to_int(c): int 与 int_to_char(n): char： 二者不产生任何 LLVM 指令（char 与 int 同表示），纯粹是编译期的类型视图切换。
  • C Runtime dial_print_char：按 UTF-8 编码输出 1~4 字节。 非法码点（负数、> 0x10FFFF、UTF-16 代理区 D800~DFFF）当场打印诊断并终止。
  • 正向示例 examples/char_demo.dial（含多字节 UTF-8 中 / é）； 负向用例 5 个（char 算术 / char 与 int 混用 / char_to_int 传 int / int_to_char 传 char / int 赋给 char 变量）。

Changed（语义与规则变更）

  • 统一容器写回规则：废除 m = m.put(1, 1) 这类手写赋值，与数组 push 统一—— 所有原地修改并触发 COW 的方法（push / put），编译器自动写回，严禁用户手写赋值。 现在 a = a.push(...) / m = m.put(...) 会在编译期被拒绝 （把结果赋给另一个变量仍然允许，那是取新容器而非就地修改）。
  • 版本号规则重写：废弃此前的「十进制递增 / 三段式」表述，改为 最多两位小数（v0.1…v0.9、v0.91、v0.92），版本标题统一为 [v0.92] 而非 [0.92.0]， 且版本号必须严格按时间递增、绝不倒流。
  • 许可隔离声明（README §3.3.1 / §25.8 / LICENSE）：明确按组件划分—— 编译器前端为三重许可，但被静态链入用户程序的 libdial_std.a 强制锁定为 MIT / Apache-2.0，绝不允许以 GPL 条款链接进闭源程序。

Fixed（修复）

  • 未捕获异常打印出乱码（真实缺陷）：dial_error_msg 返回的是不透明 DialString 句柄， 却被直接当作 const char* 传给 dial_panic，导致 panic 只打印出一个数字（实测 9）而非错误消息。 已补上 dial_string_cstr 转换，现在正确输出 dial: 未捕获的异常（panic）: 无法打开文件（路径不存在或无访问权限）。 新增测试组 G 锁定该契约。
  • §27.9.5 的 select 空转教程自相矛盾：原文称「while (true) { select { ... } }」本身安全， 实则全体 EOF 时 select 只是**直接结束**、不会跳出循环，于是每轮立刻结束又立刻重入， 构成 **100% CPU 空转死循环**（实测 5 秒超时、exit 124）。 已改为演示两种安全退出写法，并各配一个可运行正例（连跑 10 次输出稳定）：examples/select_exit_condition.dial（while (not done(ch))）与examples/select_exit_break.dial（case 内break`）。
  • §26.1 异常语法漏洞：原文笼统断言「throw 必须出现在 try 块内」，混淆了两种情形。 现明确区分（§26.1.1）：显式 throw Error(...) 不在 try 内 → 编译期报错； 内建函数的隐式抛出（open / read / write 失败）允许写在任何地方 → 编译通过， 运行到该处若无捕获则触发未捕获异常 panic 终止。
  • 首页示例使用 + 拼接字符串：Dial 的字符串没有 + 运算符，已改为 print("hello, ".concat(name)) （同步修正生成器 tools/build_web.py 与产物 web/index.html，避免重新生成时复发）。

验证

  • A/B/D/E/C/F 六组原有测试全绿，新增 G 组（未捕获异常契约）通过。
  • 新增 5 个 char 负向用例 + 2 个写回规则负向用例 + 2 个 select 安全退出正例，均纳入自测。
