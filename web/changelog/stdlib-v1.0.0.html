[stdlib v1.0.0] — 2026-10-31（独立 Release，tag stdlib-v1.0.0）

官方标准库（由 stdlib/ + runtime/ 编译归档而成的 libdial_std.a，被每一个 Dial 程序静态链入） 改造为 .dialpkg 形态，独立发版、与 dialc 编译器解耦，走 GitHub Releases 分发。

Added（新增）

  • stdlib.dialpkg 包：单包含三平台预编译静态库 （lib/x86_64-linux-gnu/libdial_std.a · lib/x86_64-pc-windows-gnu/libdial_std.a · lib/aarch64-unknown-linux-musl/libdial_std.a），manifest.txt 记录 name=stdlib / version=1.0.0 / abi=1 / license=MIT OR Apache-2.0 与各平台机器码 SHA256。
  • stdlib/stdlib.diali：与 declare_stdlib() 逐条对齐的接口签名文件，供 .dialpkg 自描述与校验。
  • tools/build_stdlib.sh：统一选 zig cc/clang/gcc + ar，把 runtime/*.c + stdlib/*.c 编译归档为单份 libdial_std.a（默认 -DDIAL_SAFETY=1 ReleaseSafe 预编译）。
  • tools/make_stdlib_pkg.py：收三平台 .a 与 .diali，算 SHA256、生成 manifest.txt 并打包 stdlib.dialpkg。
  • dialc 链接期自动链入：src/main.rs::link() 优先 package::find_installed("stdlib") 取本平台 .a 链入，日志打印「使用已安装的标准库包: stdlib v1.0.0（ABI 1，目标 …）」； 未安装则回退实时编译 stdlib/ + runtime/ 源码（默认 Debug），任何环境都能编出程序。
  • ABI 兜底：已装包 manifest.abi ≠ package::STDLIB_ABI（新增常量，锁定为 1）即当场报错并给出重装方案 （rm -rf ~/.dial/packages/stdlib 后重装），绝不静默崩溃。
  • 一键脚本自动安装：tools/install-dial.sh / install-dial.ps1 装好 dialc 后静默从 Release stdlib-v1.0.0 拉取 stdlib.dialpkg 并执行 dialc install（STDLIB_RELEASE 可钉版本，离线/失败仅告警）。
  • CI 自动发布：.github/workflows/ci.yml 在 stdlib-v* 标签触发 publish-stdlib 作业， 由 build-linux / build-windows / build-termux 各自产出本平台 .a 后打包发布。

Changed（变更）

  • 预编译安全等级统一为 ReleaseSafe（-DDIAL_SAFETY=1）：C Runtime 层越界/空指针等 UB 由 ud2 Fail-Fast 拦下，兼顾性能与安全；与用户程序自身 --release/--fast 等级是两回事（标准库等级发布时已钉死）。

Docs（文档）

  • ARCHITECTURE.md §8 阶段 7 标 ✅；README §25 新增 §25.10「官方标准库 stdlib.dialpkg（独立发布）」； §25 顶部状态注释同步（URL 安装 / 一键脚本 / stdlib 化均已落地）。
